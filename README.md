# 🏎️ Scroll-Driven Hero Section Animation

An interactive, high-performance scroll-driven hero section built for the **Itzfizz Digital Web Development Internship Assignment**. This project features smooth GPU-accelerated motion graphics, glassmorphism UI components, and dynamic scroll pinning powered by React and GSAP ScrollTrigger.

🚀 **Live Demo:** [itzfizz-assignment-hazel.vercel.app](https://itzfizz-assignment-hazel.vercel.app/)

---

## ✨ Key Features

- **Initial Entrance Sequence:** Letter-by-letter animated headline reveal (`WELCOME ITZFIZZ`) alongside staggered metric card entrances upon page load.
- **ScrollTrigger Pinning & Scrubbing:** Hero section pins seamlessly while the dynamic visual element navigates across a multi-waypoint path synchronized directly to scroll progress.
- **Glassmorphism UI Cards:** Modern visual statistics display using ambient glow effects and vibrant sunset gradients.
- **Responsive & Performant:** Built with CSS Grid/Flexbox and GPU-accelerated transforms (`will-change: transform`) ensuring high frame-rate rendering across desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/) (Vite)
- **Animation Engine:** [GSAP](https://gsap.com/) & [ScrollTrigger Plugin](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)
- **Styling:** Modern CSS3 (Custom Properties, Glassmorphism, Responsive Grid)
- **Deployment:** [Vercel](https://vercel.com/)
